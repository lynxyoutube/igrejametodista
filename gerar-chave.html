Criptografar Token (chave.json)

Ferramenta local segura para gerar o arquivo de autenticação

🔒 Privacidade Total: Todo o processo roda 100% no seu navegador usando a Web Crypto API (PBKDF2 com SHA-256 em 600.000 iterações + AES-GCM 256 bits). O seu token não é enviado para nenhum servidor e nem sai do seu computador.
Fine-grained token com permissão "Contents: Read and write" no repositório igrejametodista.
Esta é a senha que sua irmã digitará no site para liberar os campos e salvar.

Como obter o token fine-grained no GitHub:

  1. No GitHub, clique na sua foto de perfil → Settings → Developer Settings (no final da barra lateral).
  2. Em Personal access tokens, selecione Fine-grained tokens e clique em Generate new token.
  3. Defina um nome (ex: Escala Igreja) e uma data de validade (Expiration).
  4. Em Repository access, selecione Only select repositories e escolha igrejametodista.
  5. Em Permissions → Repository permissions, encontre Contents e selecione Read and write.
  6. Clique em Generate token e cole o token aqui em cima.

Depois de gerar o chave.json, mova o arquivo para a raiz da pasta do site e faça o git push.
